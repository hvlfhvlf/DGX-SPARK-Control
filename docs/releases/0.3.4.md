# 0.3.4 — boot-autostart switch

2026-11-11 · Ubuntu 24.04 ARM64 / NVIDIA DGX Spark.

## Change / 변경

Service Details now uses the same rectangular switch as Settings for **Start when Spark boots**. The visual track is 40 × 24 px with a 14 px square thumb, inside a 44 × 44 px button. On/off use accessible switch semantics; unknown state is a disabled dash, not an inferred off state. Saving locks repeat input. Theme colors and keyboard activation are retained.

서비스 상세의 부팅 자동 시작을 설정 화면과 같은 사각형 스위치로 통일했습니다. 켜짐·꺼짐·미확인·저장 중 상태를 구분합니다. 자동 시작 API와 실제 실행 제어, 인증·설정 스키마는 변경하지 않습니다. 현재 실행 중인 모델을 시작하거나 중단하는 스위치가 아닙니다.

## Validation / 검증

- Linux Python: 94 tests passed. Node: 59 tests passed. Web JavaScript and shell syntax checks passed.
- Browser: checked/unchecked state and 44px hit area inspected; desktop and 390/320px layouts checked for horizontal overflow. The same UI was privately deployed as 0.3.4~rc1 before this release.
- Spark package upgrade, authenticated health, installed-code identity, preserved settings/password/session files and unchanged model-service processes checked before publication.
- Source and package scans compare known local secrets and private identifiers, reject forbidden private files, and check normalized archive/package ownership. Git history and archive-to-source identity are reviewed. These checks are not a mathematical guarantee against every possible secret format.
- The public release assets are built from the tagged source. Post-publication unauthenticated download/checksum and public-package installation results are recorded in the GitHub Release and project release log.

## Scope and recovery / 범위·복구

Korean/English quickstart, user and LLM guides are aligned to 0.3.4. Install the new `.deb` with apt; settings and remembered logins remain outside package files. See [updates and recovery](../UPDATES.md). Monitoring remains capped at 480 MiB, with no new daemon or polling.

This is a UI release. Production model autostart settings were not toggled, and the host was not rebooted or powered off for validation. Physical iPhone Safari, a new long-duration soak and upstream application upgrades were not repeated. Existing service-update limits and earlier verification remain documented in [0.3.3](0.3.3.md) and [service updates](../SERVICE-UPDATES.md).

이번 검증은 반응형 브라우저 크기 검사이며 실제 iPhone Safari 검증은 아닙니다. 운영 모델의 자동 시작 설정을 바꾸거나 재부팅하지 않았습니다. 앱 업데이트의 임시 자원·백업 제한은 기존과 동일합니다.
