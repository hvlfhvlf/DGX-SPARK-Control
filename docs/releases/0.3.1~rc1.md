# 0.3.1~rc1 — local candidate

Not published to GitHub. Source is an uncommitted working-tree candidate.

Adds actual TensorFold loading counters, a single recovery attempt after failed starts, explicit warnings, Programs, and optional two-stage power controls. No inference configuration changes.

Validation and deployment evidence is recorded locally and in the project Notion checklist. Actual reboot/shutdown and production model restart are deliberately not executed during validation; fixed-action dispatch is tested with mocks and readiness/recovery with a disposable service.
