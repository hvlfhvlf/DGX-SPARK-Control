# 0.3.0 — 2026-11-03

Public release of the rc1–rc4 service/telemetry work. Runtime code is unchanged from rc4; this release updates version, privacy exclusions and Korean/English documentation.

## User changes

- Registered user-service start/stop/restart and stopped-profile selection; bounded operation history and read-only discovery.
- App links and full model/quantization/inference/serving labels; display editing and shared service order.
- Compact phone cards in two columns, equal-width Confirm/Cancel and eight real-data detail views with right-aligned notes. SSD capacity uses a breakdown, without a time chart.
- Existing engine installations are preserved. Automatic model installation/deletion, engine-specific hot loading and automatic switch rollback remain out of scope.

## Validation scope

The rc4 runtime passed 33 Linux unit/API tests and 7 telemetry-data tests. Korean/English browser checks covered 1440/390/320 px: 48 metric-detail and 6 editor layouts without overflow, plus persistence/cancellation/order checks. Earlier rc1 validation exercised a disposable systemd service and package rollback/reapply; real model services were not stopped for those checks.

Publication checks on 2026-11-03 passed: 33 Linux tests, 7 telemetry tests, all web JavaScript syntax and bash syntax. Source/history inspection and archive/deb control/data inspection found no known private values, recognizable secret patterns, prohibited private files or personal owner metadata. Loopback examples and synthetic test credentials are intentionally retained.

The existing Spark was updated to 0.3.0, rolled back to rc4 and reapplied with authenticated health checks. Settings, password/session/maintenance-token files, service registry and operation history were preserved; model services and the ComfyUI connection gateway retained their process identities. Installed runtime assets matched the tested source. A post-install observation was 58,519,552 bytes (about 55.8 MiB) with a 503,316,480-byte limit and swap disabled; the inherited cgroup peak was 73,764,864 bytes. This is an observation, not an inference performance benchmark.

The release assets are built from the exact tagged Git tree. Final asset hashes and the post-publication download/install verification are recorded in GitHub Release notes and the project release record. No private paths, hostnames, Tailscale addresses, actual model registry, credentials or raw logs are attached.

Physical iPhone/Safari, clean new-OS installation, long-running inference overhead and model inference quality are not certified by this release. Existing GTK/setup validation is inherited from 0.2.x; this release does not alter that UI.

## Migration and recovery

Config/auth schema 1 and service registry schema 1 remain. Legacy config.models migrates once. Device login sessions have no fixed expiry. Package updates restart the dashboard/tray, not registered engines. Older 0.2.x ignores the new service registry; reapplying 0.3.0 restores that registry. Do not edit both model formats during rollback.
