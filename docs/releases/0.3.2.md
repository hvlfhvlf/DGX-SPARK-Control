# 0.3.2 — 2026-11-05

Includes the locally validated rc1/rc2 corrections and subsequent appearance/mobile work. No config/auth/registry schema migration. [한국어 LLM 안내](../LLM-GUIDE.ko.md) · [English agent playbook](../LLM-GUIDE.en.md).

## Included

- Current API health separated from historical operations; process-only app links say Open App and explain unchecked connectivity in Details.
- Readiness cache bound to systemd invocation and registry revision. Reviewed confirmations reject stale profiles/revisions; disconnected controls fail closed. Failed Stop retries Stop and late responses from an earlier login cannot update the new session.
- Semantic theme variables, three accent presets with color chips, black/white toggle and browser-local restoration. Existing fonts and chip illustration retained.
- Phone-only compact telemetry, Model Bay, service/edit dialogs and all eight metric details. Empty reserved rows removed, important readings retained, 44px actions and minimum two telemetry columns preserved. Narrow per-core 100.0% overflow corrected.
- Simplified name editing, header control alignment, removal of duplicate Settings power controls, clearer service registration/connection/state wording.
- Bilingual agent installation and Model Bay playbooks, copyable prompts, revision-safe registration, verification and recovery instructions. Future-feature research remains explicitly a plan.

## Validation scope

59 Linux Python tests and 37 JavaScript tests cover current source, including readiness invalidation, session races, action binding and theme rules. All 14 web scripts receive syntax checks; shell scripts receive bash syntax checks. Private evidence retains full output.

Authenticated Chromium inspection covered 320/390px English/Korean, black/white, Comfortable/Compact, eight metric dialogs, model cards, display/connection draft switching and discard, confirmation cancellation and scroll reset. At 390px model cards were approximately 19% shorter and Qwen service-detail content approximately 27% shorter; metric-detail content shrank approximately 14–18%. Desktop 1440×900 model/toolbar/service-detail/CPU-detail geometry was unchanged. Actual 100.0% core readings fit the corrected 320px cells.

Prior rc2 isolated user-service tests covered start, stop, restart, stopped-profile selection, failure/recovery and rejected duplicate/running-switch/unauthenticated/untrusted-origin operations. These used disposable fixtures rather than production models. The release does not change that lifecycle implementation beyond the documented readiness invalidation.

The GitHub Release records the exact source commit, SHA256SUMS, final package installation/recovery checks and public-download results. Source and packaged bytes are reviewed for known local secrets/identifiers, credential patterns, forbidden private files and archive ownership. Private settings and operational logs are excluded from source/assets. Scanning is not an absolute proof of absence.

## Installation and recovery

Install the new ARM64 `.deb` with apt; existing-password setup is not required again. Preserve the private data directory and existing model services. Dashboard/tray may restart. Do not mix archive update scripts with a package installation. See [Updates](../UPDATES.md). Device sessions retain their existing no-fixed-expiry policy; password changes/logouts still revoke access.

## Limits

No physical iPhone Safari/Firefox validation, long-duration inference performance benchmark, production model OOM injection, actual reboot/shutdown or new-OS installation is claimed. The memory cap remains 480 MiB combined for dashboard/tray; a cap or a one-time memory reading is not performance proof. Specific package/recovery checks performed for publication are listed in the GitHub Release rather than inferred from unit tests.

Model Bay registers existing user systemd services; it does not automatically install engines/weights, manage arbitrary Docker/system processes, generate launch commands from model files or hot-swap models. Metadata edits change labels, not execution. Unsupported metrics remain unavailable. Planned preflight/diagnostics, capability overview, home-screen installation and persistent token ledgers are not included.
