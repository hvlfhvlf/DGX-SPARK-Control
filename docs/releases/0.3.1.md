# 0.3.1 — 2026-11-04

Public ARM64 Ubuntu release incorporating the locally validated rc1–rc10 work. Runtime code matches rc10; this release updates version and public documentation.

## Included

Measured inference charts and selected LLM details; existing user-service discovery, reviewed connections and private model-file inventory; startup states/progress and bounded failed-start retry; Programs; searchable date-grouped activity; optional two-stage password-confirmed power actions; compact responsive layout, retained drafts and typography consistency.

## Validation

The final source is checked with 58 Linux Python tests, 24 JavaScript tests, web JavaScript and shell syntax checks. Four regressions have failing-before/passing-after coverage: late 401 responses, response-body deadlines, in-flight LLM selection and stale context metadata. Source and package checks cover known local credentials/identifiers, secret patterns, forbidden private files and normalized archive owners.

Authenticated rc10 browser audit: desktop and 320px English/Korean main views, 390px Korean telemetry and all eight detail dialogs; no horizontal overflow. Activity search/filter, editor draft retention/discard, service discovery, process search, offline/reconnect and two-stage power confirmation were checked without executing power commands. Memory remained below 110 MiB in that audit, under the unchanged combined 480 MiB cap; this is not an inference workload benchmark.

Final package installation and public-download validation results, exact source commit and SHA256SUMS are recorded in the GitHub Release. Private configuration/session hashes, operational model process identities and installed file identity are checked during update. Evidence files containing machine-local details stay outside the repository.

## Limits

No production model start/stop, real OOM recovery, actual reboot/shutdown or long-running inference benchmark was executed for this release. Lifecycle tests use isolated fixtures. Physical iPhone Safari, Firefox and clean-machine installation/rollback were not repeated in this release audit. Backend metric adapters are validated against fixtures and available endpoints, not every engine version or workload.

Registration connects an already installed user systemd service. It does not download engines/weights, generate arbitrary launch commands, manage Docker/system services or turn model files into runnable profiles. Unsupported readings remain unavailable. Power control requires explicit local administrator setup; installing this release does not grant it automatically.
