# 0.1.2 validation record — 2026-10-08

Replaces decorative diagonal text arrows with inline SVG, preserving the existing design while removing platform emoji fallback. Adds separate Korean and English user guides. No backend, model-control, Tailscale naming or authentication-policy changes.

## Validation

- All 11 existing Linux unit/API tests passed on Spark. All web JavaScript passed Node syntax checks; installer/update/rollback/tray shell scripts passed `bash -n`.
- Actual installation on Spark passed the authenticated health check. Browser reload retained the existing device login and showed version 0.1.2 with live telemetry.
- Chrome desktop (1707 CSS px) and 390/320 px mobile emulation: ten diagonal icons are SVG, zero visible diagonal-arrow text characters, no horizontal page overflow. Brand icon is 52 px on desktop and 36 px on mobile; schematic label icon is 12/11 px. All eight mobile cards retain two columns and a fixed 190 px height.
- Card details still open and close. Korean and English overview rendering preserve the same ten icons; decorative SVG is hidden from accessibility output. No icon font, image request or runtime dependency was added.
- Actual 0.1.2 → 0.1.1 rollback retained authenticated browser access; restoring 0.1.2 passed the health check. Local byte-hash comparison confirmed config, password, remembered sessions and maintenance token were unchanged. Both dashboard and tray services are active.
- Combined dashboard/tray cgroup after restoration: 50,212,864 bytes (47.9 MiB); peak during this run 60,993,536 bytes (58.2 MiB); hard limit remains 503,316,480 bytes. This is a short observation, not an inference-overhead benchmark.
- Korean and English guides have matching shell/JSON examples and resolving relative links. Both are included under docs in the release package. Published-asset verification is appended to GitHub Release notes after upload.

## Compatibility and boundaries

Configuration schema remains 1. Password hashes, remembered sessions and settings remain outside release code. The original Tailscale URL is retained. The dashboard introduces no new dependency or polling task.

SVG geometry and currentColor do not depend on an emoji font. Chrome viewport emulation is not a physical iPhone/Safari test; direct device confirmation is still needed. Previously documented hardware, engine-adapter and long-term performance limits remain applicable.
