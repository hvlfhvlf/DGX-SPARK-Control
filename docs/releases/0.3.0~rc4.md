# 0.3.0~rc4 — local UI candidate, 2026-11-02

Adds service display editing (service/model/quantization/inference/serving labels) and ordering shared across devices. Registry revision checks reject stale edits; writes remain atomic, private and authenticated. Execution bindings, app URLs and permissions are excluded. Model cards are compact with two columns on phones; add/replace instructions are collapsed. Telemetry detail notes move to the right, reducing empty summary/header space across eight metrics. The rc3 50:50 lime Confirm/red Cancel footer is retained.

GitHub push/tag/release remain on hold. Configuration/auth/registry schemas are unchanged. Previous packages remain usable with the same label fields and array order. No production service lifecycle action is needed for validation.

Validation scope: Linux unit/HTTP persistence and access checks, JS/bash syntax, responsive browser checks at desktop and 390/320 px in Korean/English, edit/save/reload/restore and reorder/save/reload/restore, cancellation and focus behavior. Package health, source/installed assets, credentials/launch settings/service PID preservation and cgroup limits are checked. Final evidence and exact source/package hashes are kept in the local verification bundle and project Notion. Physical Safari and inference performance are not tested in this candidate.
