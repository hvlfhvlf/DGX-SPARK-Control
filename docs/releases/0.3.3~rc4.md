# 0.3.3~rc4 — private candidate, 2026-11-06

Details adds a boot-autostart switch for registered user-systemd launch profiles. Reads actual UnitFileState and user lingering. Enable/disable never uses --now. Authentication/Origin checks, registry revision, explicit profile identity and the shared maintenance lock apply. Unsupported installs and conflicting auto-enabled profiles are rejected. Profile rebinding/removal is blocked until its boot setting is disabled. Existing service enabled states are not migrated or changed by installing this version.

No additional daemon or periodic poll. Existing 480 MiB dashboard/tray limit remains. UI has English and Korean labels and accessible switch semantics. The corrected Open App / lower Start-Stop + Details card arrangement is retained. Public GitHub remains v0.3.2; no commit/push/tag/release is requested.

Validation before deployment: 91 Python tests and 43 JavaScript tests passed. Auth/Origin, stale revisions, read-only profiles, conflicts, maintenance locking, linger, command failure and rebinding checks covered. A disposable real user service verified persistent default.target links, off/on setting reads, no start of an inactive service and unchanged PID for a running service. No production service was started/stopped and the host was not rebooted.

Deployment: Spark installed rc4; authenticated health and installed/source bytes matched. Existing config/auth/registry hashes and service PIDs/boot settings preserved. UI ComfyUI ON then OFF roundtrip restored the original disabled state without starting it. Desktop, 390px and 320px dialog widths showed no horizontal overflow. Real iPhone/Safari and host reboot remain untested. Dashboard/tray measured about 77 MiB current / 90 MiB peak; 480 MiB cap retained. Notion project current-state record updated.
