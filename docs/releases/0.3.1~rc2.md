# 0.3.1~rc2 — local candidate

Not published to GitHub. Based on the uncommitted rc1 candidate.

Activity groups service-control events by device-local calendar date and localizes names/actions/status. Authenticated same-origin POST /api/events/clear persists a bounded set of hidden completed operation IDs; active operations and completions newer than the reviewed cutoff survive. Operational recovery state and system journals are not deleted.

The header SVG power icon opens a restart/shutdown choice dialog. Selecting an option leads to the existing two-stage warning/password confirmation. Choosing or cancelling does not dispatch a power action. The Settings entry remains.

Validation: Linux unit/API tests, calendar boundary tests, PC/mobile browser inspection and candidate package installation. Production history is not cleared during UI tests; power actions and model restarts are not executed. Exact evidence and checksums remain in the local validation folder and Notion record.
