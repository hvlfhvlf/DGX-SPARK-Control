## iPhone compatibility and limits

WebKit supports static WOFF2 on iOS 10 and later: [official WebKit documentation](https://webkit.org/blog/6643/improved-font-loading/). This font-format support does not imply that every dashboard feature supports old iOS versions. Modern Safari can fetch the fonts from the same Spark HTTPS origin without installing them on the phone or reaching a font CDN. `font-display: swap` keeps text visible with the system fallback during loading.

No physical iPhone or Safari/WebKit runtime was available for this check. Chromium viewport tests are layout checks, not iOS certification. Font rasterization can differ slightly by OS. Clean-OS installation and long-running inference performance were not retested for this typography-only change.
