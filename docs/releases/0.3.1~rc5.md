# 0.3.1~rc5 — memory percentage

The overview memory card keeps used GiB on the left and shows used / OS-usable total as a percentage on the right, to one decimal place. It uses the same values as the existing gauge, not advertised/installed memory capacity. Missing data, disconnected state and an invalid/zero denominator display —%. CPU/GPU clocks and metric detail capabilities are unchanged.

메모리 카드 우측의 미지원 GHz 대신 OS 가용 총량 대비 사용률을 소수점 한 자리로 표시합니다. 설치 용량으로 나누지 않으며 기존 게이지와 같은 기준입니다. 데이터 미수집·연결 끊김·총량 미확인 시 —%를 표시합니다. 카드 크기와 모바일 최소 2열을 유지합니다.

Frontend-only change from rc4. Existing runtime validation and its limits are documented in [rc4](0.3.1~rc4.md). Verification evidence for this update is kept outside release source under verification/memory-percent-20261104. No GitHub or public-preview publication is requested.
