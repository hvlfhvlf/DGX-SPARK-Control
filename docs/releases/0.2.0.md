# 0.2.0 validation record — 2026-10-08

Ubuntu ARM64 `.deb` packaging, Korean/English initial setup, existing-install migration and explicit SSH/LLM setup paths. Other platforms remain on hold. Configuration schema stays at 1.

## Verified

- 17 Linux unit/API tests passed, including first-password validation, readonly checks, migration failure restoration and dashboard-specific Tailscale route detection.
- Python and shell syntax checks passed; a non-root ARM64 `.deb` build succeeded with declared GTK/tray dependencies.
- Actual apt installation on Spark succeeded. Existing installation was identified, then noninteractive activation passed authenticated health/version checks.
- Config, password, remembered sessions and maintenance token byte hashes matched before/after migration. Existing browser access opened 0.2.0 without another login at the unchanged Tailscale URL.
- Server and tray active. Initial observation: combined 50,360,320 bytes (48.0 MiB), peak 67,768,320 bytes (64.6 MiB), cap 503,316,480 bytes (480 MiB).
- Actual GTK widget trees rendered offscreen in English and Korean; invalid empty password blocked progress, and a mocked successful installer reached completion and cleared password fields. This is widget rendering/state verification, not a physical desktop click-through.

- Actual package reinstall passed. Package removal → preserved 0.1.2 archive installation → package reinstall/activation passed. Private config/password/session/token hashes were unchanged through the full sequence.
- Fresh noninteractive setup with an empty temporary HOME returned exit code 2 and setup_required without creating user files; both archive update and rollback commands refused package-managed installs.
- Live AppIndicator menu registration includes version 0.2.0 and the three new setup/address/update actions.
- Chrome live browser retained authentication after migration and recovery. Mobile viewport checks: 390 px has two 175 px columns; 320 px has two 140 px columns; eight cards and no horizontal overflow. The desktop viewport override was cleared afterward.
- Python, all web JavaScript and installer/update/rollback shell syntax passed. Korean and English quick-start and full guides include matched workflows and explicit platform/connection limits.

Public release-asset download, checksum and reinstall confirmation is appended to the GitHub Release notes after publication, since the immutable release source is finalized before publication.

## Limits

Not a clean Ubuntu image installation or a long-running inference benchmark. Tailscale account approval, sudo authentication and GNOME extension enablement remain user steps when needed. The setup window is transient and outside the server/tray cgroup; the 480 MiB limit covers the running dashboard services. No model, driver, Tailscale routing or authentication-policy change is required.

First public `.deb`: there is no 0.1.2 package to download for downgrade. Recovery to the pre-migration archive is documented in [UPDATES.md](../UPDATES.md).
