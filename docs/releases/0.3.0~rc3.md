# 0.3.0~rc3 — local UI candidate, 2026-11-02

Service start/stop/restart confirmation now has a full-width two-column footer: Confirm in lime, Cancel in red. Buttons have equal widths and a 56 px minimum height (52 px on phones), retaining two columns at 320 px. Cancel uses the existing dismissal path and does not send a control request. The close icon, Escape and focus restoration remain available.

No backend, registry, credentials, engine configuration or polling changes. The previous rc2 behavior and validation remain documented in [rc2](0.3.0~rc2.md). GitHub publication is still on hold.

Validation: JS/bash syntax, existing Linux tests, desktop and 390/320 px dialog geometry, Korean/English labels, cancel/keyboard dismissal and no resulting control operation. Package healthcheck, settings/session/registry preservation, source/installed asset comparison and archive privacy checks are recorded in the local verification bundle and project Notion record. Real model services are not started/stopped for this UI test. Physical Safari is not tested.
