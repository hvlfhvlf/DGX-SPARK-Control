# DGX-SPARK-Control 사용자 가이드 — 한국어

**0.2.1** · [English](GUIDE.en.md) · [간편 설치](QUICKSTART.ko.md)

## 설치·접속

[간편 설치 가이드](QUICKSTART.ko.md)에 따라 `.deb`를 설치하고 앱 목록의 **DGX-SPARK-Control 초기 설정**을 엽니다. 한국어·영어를 선택하고 이름·비밀번호를 저장하면 서버가 시작됩니다. 기존 비밀번호를 유지하려면 두 칸을 비워두세요.

Spark 자체에서는 `http://127.0.0.1:8767`, 다른 기기에서는 Tailscale HTTPS 주소로 접속합니다. 트레이의 **접속 주소 복사**는 연결된 HTTPS 주소를 우선 사용합니다. Tailscale 연결이 없으면 로컬 주소를 복사하고 안내합니다.

## 로그인과 복구

같은 브라우저·같은 주소에서는 기간 제한 없이 로그인합니다. 재시작·업데이트 후에도 유지됩니다. 로그아웃, 비밀번호 재설정, 브라우저 데이터 삭제 시 해제됩니다. 다른 브라우저·주소·시크릿 창에서는 새 로그인이 필요할 수 있습니다. 최대 32개 세션이며, 33번째 발급 시 가장 오래된 세션이 제거됩니다.

비밀번호를 잊으면 Spark 로컬 트레이의 **비밀번호 재설정**을 사용합니다. 기존 비밀번호는 필요하지 않습니다. 패키지 설치판에서 터미널로 복구하려면:

```bash
python3 /usr/lib/dgx-spark-control/scripts/set-password.py
systemctl --user restart dgx-spark-control
```

비밀번호 원문은 저장하지 않습니다. 비밀번호 해시·토큰·세션 파일을 공유하거나 GitHub에 올리지 마세요.

## 실제 측정값

| 카드 | 내용 |
|---|---|
| GPU | 사용률과 지원되는 SM 클럭 |
| CPU | 전체·코어별 사용률, 읽을 수 있는 클럭 |
| 통합 메모리 | OS 사용량·총량, 지원되는 메모리 클럭 |
| SSD | `/` 파일시스템 사용량·총량·사용자 가용·예약 여유 공간 |
| GPU 온도 | 드라이버가 제공하는 온도 |
| GPU 전력 | GPU 센서 값. 전체 시스템 콘센트 전력과 다름 |
| 네트워크 | 물리 인터페이스 수신·송신 MB/s. 인터넷 트래픽만 분리한 값이 아님 |
| 디스크 I/O | 물리 디스크 읽기·쓰기 MB/s |

카드를 눌러 실제 이력과 상세값을 봅니다. 미지원·초기 준비 중 값은 `—`입니다. 설치 RAM은 읽을 수 있는 펌웨어 용량을 사용하고, 없으면 OS 총량임을 표시합니다. 64/128 GB로 임의 추정하지 않습니다. SSD 카드의 사용 비율과 `df` 퍼센트는 예약 공간 때문에 다를 수 있습니다.

## 설정과 트레이

Spark 표시 이름은 모든 기기에 반영됩니다. OS 호스트명·Tailscale 주소는 변경하지 않습니다. 웹 언어·개인화는 브라우저별 설정입니다. 설치 마법사 언어는 로컬 설정에 저장됩니다.

트레이에는 대시보드 열기, 주소 복사, 초기 설정, 업데이트 확인, 이름 변경, 비밀번호 재설정, 서버 시작·재시작, 상태, 닫기가 있습니다. 업데이트 확인은 GitHub 페이지를 열며 자동 설치하지 않습니다. 서버 재시작은 모델을 재시작하지 않습니다. 트레이를 닫아도 서버는 유지됩니다.

## 모델 관리

이미 설치된 사용자 systemd 서비스를 `config.json`에 명시적으로 등록해야 제어할 수 있습니다. 모델 후보 검색은 지정 경로에서 파일 후보를 찾는 기능입니다. 모델 다운로드·삭제·자동 등록·자동 교체는 수행하지 않습니다. 서비스 `active`와 실제 추론 준비 완료는 다릅니다.

[모델 연동 가이드](MODELS.md)를 읽고 설정을 백업한 뒤 기존 필드를 유지하며 필요한 모델만 추가하세요. 추론 tok/s·TTFT·전역 큐는 후속 어댑터 작업입니다.

## 업데이트·자원·문제 해결

`.deb` 설치판은 새 `.deb`를 설치합니다. 패키지와 예전 스크립트 방식은 혼용하지 마세요. [업데이트·복구·이전](UPDATES.md).

```bash
systemctl --user status dgx-spark-control
journalctl --user -u dgx-spark-control -n 50
tailscale serve status
systemctl --user show dgx-spark-control.slice -p MemoryCurrent -p MemoryPeak -p MemoryMax
```

서버+트레이 합산 상한은 480 MiB이며 swap은 0입니다. 브라우저·모델·설정 마법사·Tailscale은 별도입니다. 접속 요청이 없으면 지표를 수집하지 않습니다. 장시간 추론에 대한 영향은 별도 벤치마크가 필요합니다.

다른 LLM이 개발을 이어가면 [AGENTS.md](../AGENTS.md) → [구조](ARCHITECTURE.md) → [모델](MODELS.md) → [업데이트](UPDATES.md)를 읽게 하세요. 비밀 정보는 공개 자료에 포함하지 않습니다. [이번 버전 검증 기록](releases/0.2.1.md).

## 한글 웹폰트 / iPhone

한글 웹 UI는 SUIT 2.0.5를 사용합니다. Regular(400)·SemiBold(600)·Bold(700) WOFF2 파일을 Spark에서 직접 제공하므로 iPhone에 폰트를 따로 설치하거나 외부 폰트 CDN에 접속할 필요가 없습니다. 큰 수치·영문 디스플레이에는 Rajdhani, 영어 UI에는 Chakra Petch를 유지합니다. 폰트 로딩 중이거나 로딩에 실패하면 시스템 한글 폰트로 표시합니다.

Safari는 WOFF2 웹폰트를 지원합니다. 다만 Windows와 iPhone의 글자 렌더링은 미세하게 다를 수 있습니다. [WebKit 폰트 지원 설명](https://webkit.org/blog/6643/improved-font-loading/). 앱 업데이트 후 이전 글꼴이 남으면 페이지를 새로고침하세요. 네이티브 GTK 설정창·트레이의 폰트는 이번 변경 대상에 포함되지 않습니다.
