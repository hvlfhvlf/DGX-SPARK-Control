# 실사용 개선 우선순위 · 2026-11-05

조사/기획이며 아래 기능을 이번 UI 변경에 설치한 것은 아닙니다. PC 레이아웃, 단일 Python 표준 라이브러리 서버, 480 MiB cgroup 상한, 개인 설정과 인증을 유지합니다. 다른 플랫폼 확장은 보류합니다.

## 현재 구조와 차이

우리 대시보드는 사용자 systemd 서비스 등록과 실행 프로필을 분리합니다. 검색/등록/연결 검사/표시 편집/순서 변경은 웹에서 가능하지만, 가중치 설치와 임의 실행 명령 생성은 하지 않습니다. 등록된 포트 충돌·배타 그룹·의존 서비스 검사는 이미 있고, TensorFold 시작 관찰과 일부 실패 원인도 표시합니다. 조회는 요청 기반 캐시이며 추론 기록은 제한된 메모리에 유지됩니다.

## 권장 순서

1. **P0 실행 전 점검과 실패 진단 요약**: 기존 충돌 검사 결과를 실행 전에 보여주고 가용 RAM/서비스 상태/최근 실패 이유를 한곳에 묶기. 프로필별 필요 메모리는 검증된 예산이 있을 때만 추정으로 표시. 파일 크기만으로 실행 가능 여부를 단정하지 않기. 원문 로그·프롬프트·토큰은 노출하지 않기. 기존 실패 복구 기능을 없애거나 다른 실행 서비스를 자동 종료하지 않기.
2. **P0 지원 기능 표시**: 서비스 등록/편집의 연결 검사에서 프로세스 상태, API 준비, 토큰 통계, 큐, 모델 목록, 실행 제어의 지원 여부를 각각 표시. 지원하지 않는 항목을 0으로 채우지 않기. 기존 어댑터의 지원 범위를 확장할 때 회귀 테스트 추가.
3. **P1 휴대폰 홈 화면 설치**: manifest/아이콘과 안내부터 시작. 서비스 워커는 필요할 때 별도 도입하고 API·인증·제어 응답은 캐시하지 않기. 오프라인에서는 마지막 정상값의 시각을 표시하고 모든 제어를 비활성화. iPhone Safari 실기기와 주소창/키보드/안전 영역 테스트 필요.
4. **P1 상태 경고함**: 부족한 메모리, 반복 시작 실패, API 미응답, 저장 공간 부족을 행동 가능한 문장으로 표시. 기존 샘플 재사용, 누락값 제외, 지속 시간과 해제 조건으로 깜빡임 방지. 상시 알림은 별도 선택 설정과 부하 측정 후 도입.
5. **P1 설정 백업/복원과 수동 업데이트 확인**: 표시/프로필/연결 설정의 내보내기를 검토 가능한 형식으로 제공. 개인 주소·경로가 포함될 수 있음을 명시하고 인증 비밀은 제외. 복원은 스키마 검사 및 미리보기 후 적용. 업데이트는 현재/대상 버전·변경점·복구 경로 확인 후 명시 실행.
6. **P2 토큰 장부·추론 품질 지표**: TTFT/TPOT/큐/KV cache는 지원 엔진만. 선택적 시간별 집계, 보존 기간/DB 크기 제한, CSV 내보내기. 평균/최댓값과 실시간 속도·완료 요청 집계의 의미를 구분.
7. **P2 설치 마법사**: 엔진별 승인된 템플릿과 모델 파일 선택을 연결. 다운로드 크기·호환성·디스크 공간·실행 인자·라이선스 확인이 선행되어야 함. 임의 명령 실행 폼은 만들지 않기.

우선 적용 권고: P0 두 항목 → 휴대폰 설치와 상태 경고함. 다중 장치, 벤치마크, 비용 비교, 외부 모니터링 스택은 현재 단일 Spark 용도에서 후순위입니다.

## 검증 기준

새 기능마다 320/390px 모바일과 PC, 한/영, 블랙/화이트를 확인합니다. 시작 실패·연결 끊김·다른 기기의 설정 변경·세션 만료·재시작 후 복구를 포함합니다. 실제 작업 중인 모델을 중단하지 않고 격리된 서비스/레지스트리로 제어를 검증합니다. 자원 비용은 추측하지 않고 idle/조회/부하 시 cgroup 측정으로 기록합니다.
